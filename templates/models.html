HOW THE MODEL WAS BUILT

From raw data to one saved model

Every algorithm was prepared and evaluated in exactly the same way.

Clean

Treated 2,100 missing values across 10 columns, giving 5,000 complete customer records

Encode

Converted subscription type, payment method and favourite genre into numerical form using one-hot encoding

Split

Divided the data 70 / 30: 3,500 records for training and 1,500 for testing

Select

The chi-square test scored how strongly each feature relates to churn, using the training data only. The 7 strongest were kept for the model. Note: monthly_fee and subscription_type_Premium are both derived from subscription_type, so the prediction interface requires 6 inputs to generate these 7 features.

Scale

Standardised all features with StandardScaler, fitted on the training data and applied to the test data and live predictions

Compare

Trained 10 classification algorithms and ranked them by test accuracy

Save

Saved the final XGBoost model and scaler for generating predictions
